How it works. Tapping a bulb flips it and every bulb a knight's move away (on, or off if already lit). Hover a square to see its links. Any size from 2×2 to 10×10 can be solved from all dark. Order never matters, and tapping a bulb twice cancels out, so a solution is just a set of squares to tap once. You get 2 hints per puzzle; each one marks a single good next tap.
